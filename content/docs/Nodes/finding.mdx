---
title: Finding nodes
description: How to find the Engine User Settings nodes in the Blueprint editor.
---

<Steps>
  <Step>
    Right-click anywhere in a Blueprint graph to open the action menu.
  </Step>
  <Step>
    Type the name of the node, or scroll down to the **EngineUserSettings** category. Every node on this site has a copy button (top-right corner of the graph) that copies its name so you can paste it straight into the search box.
  </Step>
  <Step>
    <ImageZoom src="/img/searchbox.png" alt="Blueprint action menu showing the EngineUserSettings category" width={340} height={339} />
  </Step>
</Steps>

## Reading the node diagrams

<UFunction
  name="Example Function"
  target="Engine User Settings"
  inputs={[{ name: "Controller", type: "object" }, { name: "Quality", type: "int", defaultValue: 3 }]}
/>

| Header color | Meaning |
| ------------ | ------- |
| Blue | Callable function – has execution (white) pins and must be connected to the exec chain. |
| Green | Pure function – no execution pins, evaluated when its output is read. |
| Red | Event – fires when something happens. |

Pin colors follow Unreal's defaults: <span className="font-semibold" style={{color:"#a30000"}}>Boolean</span>, <span className="font-semibold" style={{color:"#00786a"}}>Byte / Enum</span>, <span className="font-semibold" style={{color:"#1fe3ad"}}>Integer</span>, <span className="font-semibold" style={{color:"#ff00d4"}}>String</span>, <span className="font-semibold" style={{color:"#00a8f4"}}>Object</span> and <span className="font-semibold" style={{color:"#ff3a3a"}}>Delegate</span>.
