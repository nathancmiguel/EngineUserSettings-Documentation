## Static nodes and subsystem nodes

Every node lives in **`EngineUserSettingsSubsystem`**, a Game Instance Subsystem. There are two kinds:

| Kind | How to call it | Examples |
| ---- | -------------- | -------- |
| **Static** | Call it directly, no reference needed. Works in menus and Editor Utility Widgets. | Rendering, shadows, Lumen, post processing, LOD, RHI, presets |
| **Subsystem** <UEVersion tone="since">Subsystem</UEVersion> | Needs the subsystem as **Target**: use **Get Game Instance Subsystem** with the class `EngineUserSettingsSubsystem`. | Upscaling, dynamic resolution, textures / VRAM, background, PSO progress, hardware info, Auto Configure |

## How settings are saved

- Settings are **applied immediately** (except RHI and feature level, which need a restart).
- They're **saved in `GameUserSettings.ini`** and **reapplied when the game starts**: console variables in `[/Script/Engine.RendererSettings]`, the plugin's own settings in `[/Script/EngineUserSettings.EngineUserSettingsConfig]`.
- Every value is **clamped to a safe range**, so a hand-edited ini file can't break the game.
- **Getters return the value in effect**, so a settings menu can read its initial state from them.

## Reading the node diagrams

| Header color | Meaning |
| ------------ | ------- |
| Blue | Callable function – has execution (white) pins and must be connected to the exec chain. |
| Green | Pure function – no execution pins, evaluated when its output is read. |
| Red | Event – fires when something happens. |

Pin colors follow Unreal's defaults: <span className="font-semibold" style={{color:"#a30000"}}>Boolean</span>, <span className="font-semibold" style={{color:"#00786a"}}>Byte / Enum</span>, <span className="font-semibold" style={{color:"#1fe3ad"}}>Integer</span>, <span className="font-semibold" style={{color:"#9dff4a"}}>Float</span>, <span className="font-semibold" style={{color:"#ff00d4"}}>String</span>, <span className="font-semibold" style={{color:"#0058c9"}}>Struct</span>, <span className="font-semibold" style={{color:"#00a8f4"}}>Object</span> and <span className="font-semibold" style={{color:"#ff3a3a"}}>Delegate</span>.
