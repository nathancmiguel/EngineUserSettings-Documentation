## Latency

### Set Low Latency Mode

Low input latency: the game thread waits for the GPU (`r.GTSyncType` 1) and the render thread may not lag one frame behind. Lower latency, slightly lower frame rate.

<UFunction

## Background

### Set Background Settings

<UEVersion tone="since">Subsystem</UEVersion>

Lower frame rate (and optionally volume) while the window is unfocused or minimized.

<UFunction
  name="Set Background Settings"
  target="Engine User Settings Subsystem"
  inputs={[{ name: "Target", type: "object", typeName: "Engine User Settings Subsystem" }, { name: "Settings", type: "struct", typeName: "FEUSBackgroundSettings" }]}
/>

<UStruct
  name="FEUSBackgroundSettings"
  description="Saves GPU/CPU (and battery) while the game window is not in front."
  fields={[
    { name: "Enabled", type: "bool", defaultValue: "false" },
    { name: "Unfocused Fps", type: "int", defaultValue: "30", range: "5 – 120", description: "Frame rate limit while the window is visible but not focused." },
    { name: "Minimized Fps", type: "int", defaultValue: "5", range: "1 – 60", description: "Frame rate limit while the window is minimized." },
    { name: "Unfocused Volume", type: "float", defaultValue: "-1.0", range: "… – 1", description: "Audio volume while unfocused (0..1); negative keeps the project's setting." },
  ]}
/>
