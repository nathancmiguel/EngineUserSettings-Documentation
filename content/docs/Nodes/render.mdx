---
title: Rendering
description: Change global illumination, reflections, shadow method, MSAA, ambient occlusion, bloom, motion blur, lens flares, Nanite and MegaLights at runtime.
---

These nodes are **static**: they don't need a subsystem reference and also work in menus and Editor Utility Widgets. Values are applied immediately, clamped to a safe range, saved to `[/Script/Engine.RendererSettings]` in `GameUserSettings.ini` and reapplied when the game starts. A quality of `0` turns the effect off.

<Callout type="info">Anti-aliasing moved to [Set Upscaler](/docs/Nodes/upscaling#set-upscaler) in v1.4.0. Coming from v1.1? See [Upgrading](/docs/upgrading).</Callout>

## Lighting, shadows & post effects

### Set Global Illumination

Dynamic global illumination. None is the cheapest; Lumen the most expensive.

<UFunction
  name="Set Global Illumination"
  target="Engine User Settings Subsystem"
  inputs={[{ name: "Method", type: "enum", typeName: "EEUSGlobalIllumination", defaultValue: "None" }]}
/>

<UEnum
  name="EEUSGlobalIllumination"
  values={[
    { name: "None", description: "No dynamic GI (baked lighting only): cheapest." },
    { name: "Screen Space (SSGI)", description: "Screen space GI: low cost, limited to what is on screen." },
    { name: "Lumen" },
  ]}
/>

### Get Global Illumination

Returns the value in effect. See [Set Global Illumination](#set-global-illumination).

<UFunction
  name="Get Global Illumination"
  target="Engine User Settings Subsystem"
  pure
  outputs={[{ name: "Return Value", type: "enum", typeName: "EEUSGlobalIllumination" }]}
/>
