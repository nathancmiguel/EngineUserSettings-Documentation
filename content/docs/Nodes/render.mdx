---
title: Render
description: Change global illumination, reflections, shadows, anti-aliasing, post-processing, Nanite and MegaLights at runtime.
---

The render nodes change console variables through the given player controller and save them to the `[/Script/Engine.RendererSettings]` section of `GameUserSettings.ini`. Saved values are restored automatically when the game starts (see [Common issues](/docs/issues#my-settings-are-not-restored-on-startup)). Unlike RHI and shader model changes, they apply **immediately**.

## Global illumination

### Set Global Illumination Method <UEVersion>UE5 only</UEVersion>

Changes the dynamic global illumination method (`r.DynamicGlobalIlluminationMethod`).

<UFunction
  name="Set Global Illumination Method"
  target="Engine User Settings"
  inputs={[
    { name: "Controller", type: "object", typeName: "Player Controller", description: "Player whose console receives the command." },
    { name: "GIMethod", type: "enum", typeName: "EDynamicGlobalIlluminationMethod", defaultValue: "Lumen", description: "New global illumination method." },
  ]}
/>

<UEnum
  name="EDynamicGlobalIlluminationMethod"
  values={[
    { name: "None", cvar: 0, description: "No dynamic GI." },
    { name: "Lumen", cvar: 1, description: "Lumen global illumination." },
    { name: "Screen Space", cvar: 2, description: "Screen space GI (SSGI), cheaper but limited to what is on screen." },
    { name: "Plugin", cvar: 3, description: "GI provided by a third-party plugin." },
  ]}
/>
