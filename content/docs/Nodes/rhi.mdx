---
title: RHI
description: Switch the graphics API between DirectX 11, DirectX 12 and Vulkan.
---

The RHI (Render Hardware Interface) is the graphics API used by the engine. The choice is saved to `[D3DRHIPreference] PreferredRHI` in `GameUserSettings.ini`.

<Callout type="warn">The game must be restarted for a new RHI to take effect.</Callout>

<UEnum
  name="EGraphicsRHI"
  values={[
    { name: "DirectX 12", cvar: "dx12", description: "Required for SM6, Lumen hardware ray tracing, Nanite and Virtual Shadow Maps." },
    { name: "DirectX 11", cvar: "dx11", description: "Widest compatibility. SM6 isn't available and falls back to SM5." },
    { name: "Vulkan", cvar: "vulkan", description: "Cross-platform API; must be enabled in Targeted RHIs." },
  ]}
/>

## Set Preferred RHI

Saves the RHI that will be used the next time the game starts. The currently preferred feature level is re-applied so it stays valid for the new RHI.

<UFunction
  name="Set Preferred RHI"
  target="Engine User Settings BPLibrary"
  inputs={[{ name: "Graphics RHI", type: "enum", typeName: "EGraphicsRHI", defaultValue: "DirectX 12", description: "RHI to use after a restart." }]}
/>

## Get Preferred RHI

Returns the RHI that will be used when the game is restarted. Returns **Vulkan** when nothing has been saved yet.

<UFunction
  name="Get Preferred RHI"
  target="Engine User Settings BPLibrary"
  pure
  outputs={[{ name: "Return Value", type: "enum", typeName: "EGraphicsRHI" }]}
/>

## Get Current RHI

Returns the RHI the game is running with right now (DirectX 12, DirectX 11, otherwise Vulkan).

<UFunction
  name="Get Current RHI"
  target="Engine User Settings BPLibrary"
  pure
  outputs={[{ name: "Return Value", type: "enum", typeName: "EGraphicsRHI" }]}
/>
