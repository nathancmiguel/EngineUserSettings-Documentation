---
title: RHI
description: Switch the graphics API between DirectX 11, DirectX 12 and Vulkan.
---

The RHI (Render Hardware Interface) is the graphics API used by the engine. The choice is saved to `[D3DRHIPreference] PreferredRHI` in `GameUserSettings.ini`.

<Callout type="warn">The game must be restarted for a new RHI to take effect.</Callout>

<Callout type="info">Since v1.4.0 the RHI getters return **Unknown / Default** when nothing is saved (project default) instead of Vulkan. Pass **Unknown / Default** to Set Preferred RHI to go back to the project's default.</Callout>

### Set Preferred RHI

Graphics API used at next start; Unknown returns to the project's default. Keeps the preferred feature level.

<UFunction
  name="Set Preferred RHI"
  target="Engine User Settings Subsystem"
  inputs={[{ name: "Graphics RHI", type: "enum", typeName: "EGraphicsRHI", defaultValue: "DirectX 12" }]}
/>

<UEnum
  name="EGraphicsRHI"
  values={[
    { name: "DirectX 12" },
    { name: "DirectX 11" },
    { name: "Vulkan" },
    { name: "Unknown / Default", description: "Not set (engine default) or not one of the above (e.g. Null RHI)." },
  ]}
/>
