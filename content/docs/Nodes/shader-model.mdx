---
title: Shader Model
description: Switch between SM6, SM5 and Performance Mode (ES 3.1), and check what the player's GPU supports.
---

<UEVersion>UE5 only</UEVersion>

The feature level controls which shader model the renderer uses. The choice is saved to `[D3DRHIPreference] PreferredFeatureLevel` in `GameUserSettings.ini` and applied at the next start.

<Callout type="warn">The game must be restarted for a new feature level to take effect.</Callout>

<Callout type="info">Since v1.4.0, **Set Preferred Feature Level refuses SM6 on GPUs that can't run it**: it saves SM5 instead and returns `false`. Otherwise the engine would silently fall back from DirectX 12 to DirectX 11 on the next start. Use [Is Feature Level Supported](#is-feature-level-supported) to hide options the GPU can't run.</Callout>

### Set Preferred Feature Level

Saves the feature level used at next start. SM6 is refused (SM5 is saved instead, returns false) on GPUs that cannot run it: the engine would otherwise silently fall back from D3D12 to D3D11.

<UFunction
  name="Set Preferred Feature Level"
  target="Engine User Settings Subsystem"
  inputs={[{ name: "Shader Format", type: "enum", typeName: "EShaderFormat", defaultValue: "SM6" }]}
  outputs={[{ name: "Return Value", type: "bool" }]}
/>

<UEnum
  name="EShaderFormat"
  values={[
    { name: "SM6" },
    { name: "SM5" },
    { name: "Performance Mode" },
    { name: "Invalid" },
  ]}
/>

### Get Preferred Feature Level

Returns the feature level saved for the next start, or Invalid when nothing is saved.

<UFunction
  name="Get Preferred Feature Level"
  target="Engine User Settings Subsystem"
  pure
  outputs={[{ name: "Return Value", type: "enum", typeName: "EShaderFormat" }]}
/>

  outputs={[{ name: "Return Value", type: "enum", typeName: "EShaderFormat" }]}

<UFunction

### Is Feature Level Supported

Whether this machine can run GraphicsRHI at ShaderFormat (SM6 needs D3D12/Vulkan and a GPU with Shader Model 6).

<UFunction
  name="Is Feature Level Supported"
  target="Engine User Settings Subsystem"
  pure
  inputs={[{ name: "Graphics RHI", type: "enum", typeName: "EGraphicsRHI", defaultValue: "DirectX 12" }, { name: "Shader Format", type: "enum", typeName: "EShaderFormat", defaultValue: "SM6" }]}
  outputs={[{ name: "Return Value", type: "bool" }]}
/>

<UEnum
  name="EGraphicsRHI"
  values={[
    { name: "DirectX 12" },
    { name: "DirectX 11" },
    { name: "Vulkan" },
    { name: "Unknown / Default", description: "Not set (engine default) or not one of the above (e.g. Null RHI)." },
  ]}
/>
