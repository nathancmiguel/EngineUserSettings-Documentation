---
title: Shadows
description: Shadow map resolution, shadow distance, cascades, contact shadows and Virtual Shadow Map settings.
---

Static nodes, applied immediately, saved and reapplied at startup. Use [Set Shadow Method](/docs/Nodes/render#set-shadow-method) to switch between shadow maps and Virtual Shadow Maps.

### Set Shadow Resolution

Maximum shadow map size in texels (128..8192), for regular and cascaded shadow maps. 1024 is a good low setting.

<UFunction
  name="Set Shadow Resolution"
  target="Engine User Settings Subsystem"
  inputs={[{ name: "Max Resolution", type: "int", defaultValue: 0 }]}
/>

### Get Shadow Resolution

Returns the value in effect. See [Set Shadow Resolution](#set-shadow-resolution).

<UFunction
  name="Get Shadow Resolution"
  target="Engine User Settings Subsystem"
  pure
  outputs={[{ name: "Return Value", type: "int" }]}
/>

### Set Shadow Distance Scale

Directional light shadow distance multiplier (0.1..2, 1 = project default). Lower is faster.

<UFunction
  name="Set Shadow Distance Scale"

  inputs={[{ name: "Scale", type: "float", defaultValue: "0.0" }]}
/>

<UFunction

  outputs={[{ name: "Return Value", type: "float" }]}
/>

### Set Virtual Shadow Map Resolution Bias

Virtual shadow map resolution bias (-2..4): 0 = full resolution, 1 = half, 2 = quarter; negative is sharper and slower. Applied to directional and local lights.

  target="Engine User Settings Subsystem"
