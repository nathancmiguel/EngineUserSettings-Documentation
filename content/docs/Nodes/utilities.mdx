---
title: Utilities
description: Write values to GameUserSettings.ini.
---

Use this node to persist your own settings, or any value the plugin doesn't save for you. The file is flushed to disk **without** being removed from the config cache, so `UGameUserSettings` keeps working with the same values.

<Callout type="info">Renamed from *Set Game User Settings Ini Value* in v1.4.0. Existing Blueprints are redirected automatically.</Callout>

### Set User Settings Ini Value

Writes Key=Value in Section of `GameUserSettings.ini` and saves the file.

<UFunction
  name="Set User Settings Ini Value"
  target="Engine User Settings Subsystem"
  inputs={[{ name: "Section", type: "string" }, { name: "Key", type: "string" }, { name: "Value", type: "string" }]}
/>

<Callout type="info">
  Keys saved in `[/Script/Engine.RendererSettings]` that match one of the plugin's console variables are clamped and applied automatically on the next startup.
</Callout>
