## Set Game User Settings Ini Value

Writes a value to `GameUserSettings.ini` and saves the file. Use it to persist your own settings, or render settings on platforms where the plugin doesn't save them for you.

Since v1.1.4 the file is flushed to disk **without** being removed from the config cache, so `UGameUserSettings` keeps working with the same values.

<UFunction
  name="Set Game User Settings Ini Value"
  target="Engine User Settings BPLibrary"
  inputs={[
    { name: "Section", type: "string", defaultValue: "/Script/Engine.RendererSettings", description: "Ini section, without brackets." },
    { name: "Key", type: "string", description: "Key inside the section, e.g. a console variable name." },
    { name: "Value", type: "string", description: "Value to save." },
  ]}
/>

<Callout type="info">
  Keys saved in `[/Script/Engine.RendererSettings]` that match one of the plugin's console variables are applied automatically on the next startup.
</Callout>

## Get Materials

Returns a soft reference to every material in the asset registry. Used by the [shader compiler](/docs/Nodes/shader-compiler).

<UFunction
  name="Get Materials"
  target="Engine User Settings BPLibrary"
  pure
  outputs={[{ name: "Return Value", type: "softobject", container: "array", typeName: "Material", description: "Every material asset of the project." }]}
/>
