## v1.1.4 — Unreal Engine 5.8 <UEVersion tone="since">Latest</UEVersion>

_Released 2026-11-07_

### Added

- Support for **Unreal Engine 5.8**.
- [Set Preferred Feature Level](/docs/Nodes/shader-model#set-preferred-feature-level) can now select **Performance Mode** (ES 3.1) when the preferred RHI is DirectX 12.

### Changed

- Saved rendering settings are restored with `IConsoleVariable::Set` (priority **SetByCode**) instead of building console commands from `GameUserSettings.ini`. The player's choice still wins over project and scalability settings, the console can still override it, and unknown console variables are ignored.
- Saving a value with [Set Game User Settings Ini Value](/docs/Nodes/utilities#set-game-user-settings-ini-value) writes the file to disk but keeps it in the config cache, so `UGameUserSettings` keeps working with it.
- The plugin descriptor now targets **Win64** only (Win32 was removed).
- Author, documentation and support links now point to the `nathancmiguel` GitHub account.

### Fixed

- [Get Preferred Feature Level](/docs/Nodes/shader-model#get-preferred-feature-level) read the wrong `GameUserSettings.ini` key (`D3D12TargetedShaderFormats`) and returned **Invalid**. It now reads `PreferredFeatureLevel`, the key written by Set Preferred Feature Level.
- [Get Current Feature Level](/docs/Nodes/shader-model#get-current-feature-level) could crash when there was no play world (main menu, editor outside PIE, map travel). It now falls back to the maximum supported feature level.
- [Is Shader Compiling](/docs/Nodes/utilities#is-shader-compiling) checks that the shader compiling manager exists and is compiled out of non-editor builds.
- Restoring settings no longer depends on `GEngine` being initialized when the module starts up.
