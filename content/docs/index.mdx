---

**Engine User Settings** is an Unreal Engine plugin that lets players customize engine features at runtime. You can switch the graphics API, the shader model / feature level, global illumination, reflections, shadows, anti-aliasing, Nanite, MegaLights and other post-process effects, and pre-compile shaders in game to remove hitches. Everything is exposed as Blueprint nodes and saved to `GameUserSettings.ini`, so the player's choices are restored on the next launch.

<Callout title="Latest release: v1.1.4 (Unreal Engine 5.8)">
  Settings are now restored with the console variable system instead of console commands, the preferred feature level is read correctly again and *Performance Mode* can be selected on DirectX 12. See the [changelog](/docs/changelog).
</Callout>

## Supported Unreal versions

| Unreal Engine 4 | Unreal Engine 5 | Platforms |
| --------------- | --------------- | --------- |
| 4.26 – 4.27     | 5.1 – 5.8       | Windows (Win64) |

## What you can change

| Area | Nodes |
| ---- | ----- |
| [Graphics API](/docs/Nodes/rhi) | DirectX 11, DirectX 12, Vulkan |
| [Shader model](/docs/Nodes/shader-model) | SM6, SM5, Performance Mode (ES 3.1) |
| [Rendering](/docs/Nodes/render) | GI method, reflections, shadows, anti-aliasing, MSAA, AO, bloom, lens flares, motion blur, Nanite, MegaLights |
| [Shader compiler](/docs/Nodes/shader-compiler) | In-game material and Niagara shader pre-compilation |
| [Utilities](/docs/Nodes/utilities) | Write any value to `GameUserSettings.ini`, list materials and Niagara systems |
